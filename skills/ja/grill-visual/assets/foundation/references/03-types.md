# 03 図とページの型

何を見せるかから型を選ぶ。型は描く前の下敷きで、描き方は毎回考える(01)。

## 標準の表現

- 場面のイラスト: 人・道具・画面を1コマに置く。人物は頭と胴の簡単な形で足り、位置・向き・持ち物で意味を伝える。
- 実物そっくりの画面のモック: PR の画面・通知・一覧・表。作り物なら「例」と書く。
- 見立ての絵: 身近な物に置き換え、上に載る中身は実物と実名(01)。
- 数のチャート: 根拠のある値だけを同じ尺度で。
- ステップ再生: 順序や受け渡しを追うとき。3〜5コマ、▶ で1コマずつ進め、「再生」を押したときだけ自動で送る。開いただけで動き続けない。
- ここに挙げた物に限らない。表現の候補を2〜3個考えてから選ぶ。


## 図の型の表

描く前に型を選び、型と骨組み(区画・流れの向き・段)を1文で書く。1文はページの図の上に「絵の型」として出す。
表に無い型でもよいが、1文は必ず書く。骨組みが決まったら、灰色の箱と線のまま出さず、絵に描き直す。

1文の例: 「流れ図。左から右へ3区画(書く → 確かめる → 公開する)。主役は PR のカードと CI の門」。

| 見せたい物 | 型 | 描き方の例 |
|---|---|---|
| 処理の順番と分かれ道 | 流れ図 | 道の上の門(遮断機)と、分かれ道の標識 |
| 人・AI・CI の間の受け渡しの順 | シーケンス | 人と AI が PR のカードを手渡す場面のコマ |
| 状態と移り変わり | 状態図 | 札が掛け替わる板、ランプの色が変わる門 |
| 担当をまたぐ流れ | スイムレーン | 担当ごとの机の列と、机の間を渡る書類 |
| 物と、そのつながり | 構成図 | 建物と道。中を通る物を実名で |
| 時間の上の出来事 | 時間軸・ガント | 日付の帯に貼った付箋 |
| 入れ子・範囲 | 入れ子 | 部屋の見取り図、棚の区画 |
| 段の重なり | 層 | 棚の段、地層の断面 |
| 数の比べ | 棒グラフ | 根拠のある値だけを同じ尺度で |
| 前と後 | Before・After | 同じ枠・同じ尺度に前と後を描き、違う所だけを変える |
| データの形 | ER 図 | 表と線。列の実名を書く |

- 表や文で足りるなら描かない。削るのが一番よい手。
- 1枚に物が多すぎるなら(目安: 物 9つ・矢印 12本を超える)、全体の絵と寄りの絵に分ける。
- 強調は1〜2か所。


## 図の決まり

| 決まり | 中身 |
|---|---|
| 一言テスト | 図が伝えることを1文で言える。言えなければ寄りの図に分ける |
| 主役は4つ前後 | 1枚で目が追う主役の物は4つ前後。多ければまとめるか、寄りの図へ |
| 描き方は1枚に1種類 | 道・梯子・輪・帯などを1枚に混ぜない |
| 線と矢印には意味の札 | 矢印は「何がどちらへ進むか」。札の無い線を引かない。線を文字や物の上に通さない |
| 色は意味の数だけ | 強調1色と状態の色で、1枚に4色まで。状態が多ければ文字の札にする |
| 札は物の隣に直接 | 離れた吹き出しや凡例に頼らない |
| 番号は重ねず、物に付ける | 番号は1枚に5つまでを目安にする |
| 最初に目が行く所 | 最初に目が行く所が、一言の主役になっている |


## 描き方(設計図の線画)

- 地に薄い方眼(16px)。区画は破線の枠と、左上に等幅の名前。
- 線の太さは3段: 区画 1・物と流れ 1.5・主役の流れ 3。
- 線は縦横に引き、角は丸める。読む向きは1つ(左から右か、上から下)。
- 矢じりは開いた V。線の太さによらず同じ大きさ。
- 物も同じ線で描き、地は面の色で抜く。強調の色は主役と押せる物だけ。
- 図は viewBox の幅 1000 前後で描き、文字は 12 以上。狭い画面では縮めずに横へ送る(04 の `.fig`)。


## ページの型

| 型 | 中身 | 持つ所 |
|---|---|---|
| ページの頭 | 何の資料か・何をしてほしいかを先に置き、見出しの下に入れ子で並べる。全体の図はそのすぐ後 | この土台(見本 `assets/sample.html`) |
| 3段(全体 → 寄り → 原文と表) | 全体の図で押した物を寄りの図で大きく描き、そこから原文と表へ進む。上の帯に今いる段を出し、押せば戻れる。前・次は行き先の名前つき | この土台 |
| 議論ページとまとめ | 論点の地図・質問ごとの図・回答欄・決定の前と後、終わったらまとめ | grill-visual |
| PR の説明・計画・レポート | Markdown の代わりに HTML で、差分・順序・数を図と表で見せる | 作り手が決める |
