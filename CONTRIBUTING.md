# Contributing

Thank you for your interest. This repository takes **issues only, not pull requests.**

- The Japanese version is the source. The English version is translated from it on every release, so a pull request to either would be overwritten.
- Open an issue with the idea or the bug. If it fits, the maintainer changes the source and releases it.
- Pull requests are closed with a pointer to Issues.

---

# 貢献について

このリポは **Issue だけを受け、PR は受けません。**
日本語版が正本で、英語版は公開のたびに訳し直すため、どちらへの PR も上書きされてしまいます。
提案や不具合は Issue に書いてください。合えば持ち主が正本を直して公開します。届いた PR は Issue へ案内して閉じます。
